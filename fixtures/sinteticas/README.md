# Notas sintéticas

Esta é a **única** pasta do repositório onde notas de corretagem podem existir,
e somente notas **fictícias, geradas do zero**: nomes, CPFs, contas, ativos,
datas e valores inventados, imitando apenas o layout público de cada corretora.

Notas reais de qualquer pessoa nunca entram aqui, nem anonimizadas. A
verificação `npm run check:privacidade` roda no CI e recusa PDFs, planilhas e
extratos fora desta pasta.
